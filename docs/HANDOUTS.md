# 讲义系统设计（第一期，2026-10-20 完成）

目标：写出“教材式”讲义——结构严谨、编号规范、版式统一。老师只管内容，字体、颜色、间距、编号全部由模板决定，网页、PDF、Word 三处一致。

## 已定的选择（用户 2026-10-20）

- 版式：教材风格（参照欧美大学教材），一套统一版式，不提供逐块改字体颜色。
- 写作：按块组织（小节 → 内容块），块的种类固定，编号自动。
- 题目：插入时存快照；题库后来改题，讲义里提示“可同步”，由老师决定是否更新。
- 导出：PDF 与 Word，各有学生版与教师版。
- 旧讲义（Word/PDF）导入：第二期。

## 结构

一份讲义属于一个空间（学科 + 学段 + 教材固定），放在“讲义”目录树（两级，同试卷目录，`folders.kind = 'lesson'`）。

```
讲义
├─ 抬头：讲次（如“第 19 讲”）、标题、副标题、学习目标（可选，若干条）
└─ 小节 1、2、3 …（自动编号）
   └─ 内容块（按顺序）
```

内容块（种类固定）：

| 块 | 用途 | 编号 | 版式要点 |
|---|---|---|---|
| 正文 | 普通段落，可含公式、加粗、列表、填空线、图片 | 无 | 段首缩进两字 |
| 定义 | 概念定义 | 定义 1.1 | 浅底色 + 左侧主色竖条 |
| 定理／性质／公式／推论 | 结论 | 定理 1.2 | 细边框 |
| 证明 | 证明过程 | 无 | “证明”标签，结尾 □ |
| 例题 | 题库题目 + 解答 | 例 1.3 | 主色标签；教师版显示解答，学生版按设置留白或显示 |
| 注／方法／易错 | 点拨 | 无 | 左侧细线 + 小标签（灰／墨／主色） |
| 练习 | 一组题库题目，带小标题（默认“练习”） | 无（题号 1、2、3…） | 编号列表；教师版答案在讲义末“参考答案” |
| 插图 | 图片 + 图注 | 图 1.1 | 居中，图注小号 |
| 本节小结 | 本节要点 | 无 | 浅灰底，上下主色细线 |

定义、定理（性质、公式、推论）、例题和插图共用一个按小节计数的编号（1.1、1.2、1.3…），和教材一致，方便课堂上说“看例 2.3”。编号不存储，网页、PDF、Word 各自按顺序算出。

正文书写约定（三端相同）：`$…$`／`$$…$$` 公式，`**加粗**`，行首 `- ` 为项目列表、`1. ` 为编号列表，空行分段，`____`（三个以上下划线）为填空横线。

## 存储

`platform.db` 新表 `handouts`：`id, space_id, folder_id, title, document(JSON), revision, created_by, updated_by, created, updated`。整份讲义存为一个 JSON 文档（版本号 `version: 1`），保存时带 `revision` 做并发保护（不一致返回 409）。题目块存快照（`handouts.SNAPSHOT_FIELDS`）：题型、题干、答案、配图路径与排版字段，加 `source_id` 和 `source_hash`（显示相关字段的 SHA-256）。`GET …/handouts/{id}/changes` 把题库当前题目按同样规则做成快照再比较哈希，返回已修改和已删除的题号；同步由老师在界面上确认，例题自写解答不变。图片仍存在空间的题库上传目录，路径保存为题库内的原始形式，读出时由平台换成浏览器地址。

## 导出

导出在空间自己的 worker 内完成（`platform_app/handout_export.py` 注册内部接口），复用引擎的题目转 LaTeX、配图收集、编译与 Word 公式转换，保证讲义里的题目与试卷排版一致。

- PDF：exam-zh 文档类作底座（选项、填空线、答题括号原样可用），叠加 `platform_app/templates/handout/mathbank-handout.sty` 的讲义版式。
- Word：`platform_app/handout_word.py`，继承引擎的 Word 试卷构建器（题目、选项、公式与试卷一致），样式与 PDF 对应（同一套颜色、层级和编号），公式为可编辑 OMML。定义、定理等用单格表格做底色与边框；题干右侧配图沿用引擎的无边框两栏行（题干左、图右，选项通栏在下，试卷同样如此），讲义只换成自己的配图尺寸，与 PDF 的 minipage 一致，在 Word、WPS、LibreOffice 中位置都确定。
- 学生版：不含答案；例题按讲义设置留白或显示解答。教师版：例题含解答，练习答案集中在“参考答案”。

## 编辑器（`platform_app/web/handouts.js`）

侧栏“讲义”（位于“试卷管理”之后）打开讲义工作区，挂载方式同“我的”：一个 `handoutWorkspaceSection`，包装 `selectWorkspace`，不改引擎脚本。

- 列表：左侧讲义目录树（`kind = 'lesson'`，交互同试卷目录：新建、子目录、重命名、删除、拖动归档），右侧讲义卡片（复制、删除、目录下拉）。
- 编辑：左大纲（可拖动调整块和小节顺序）、中间页面（按模板结构绘制：讲次、标题、学习目标、小节、各类块、参考答案；编号实时计算）、右侧设置所选内容。页面可切换教师版／学生版预览。正文用引擎的 `parseMarkdownWithMath` 处理公式与图片，段落、列表、加粗、填空线按导出规则处理；题目用 `renderBankQuestionPreview`。
- 插入：块之间的“+”与每节末“添加内容”。例题、练习从题库检索或组卷题篮选题，`/handouts/snapshots` 生成快照后插入；插图上传到空间题库的上传目录。
- 保存：停止输入约 1 秒后整份保存，带 `revision`；409 时停止自动保存，提供“另存为新讲义”或“放弃修改并载入最新”。切换工作区、返回列表、切换空间前先等保存完成；有未保存内容时关闭页面会提示。
- 只读：查看者可阅读和导出，输入框禁用，没有插入和移动入口。

## 版式规范（PDF 与 Word 共用）

- 纸张 A4；页边距上 24、下 22、左右 22 mm。
- 字体：正文思源宋体（Noto Serif CJK SC）+ XITS（西文与数学）；标题、标签用思源黑体（Noto Sans CJK SC）。Word 用宋体／Times New Roman／黑体，以适配教师电脑。
- 颜色：主色哈佛深红 `#A51C30`，只用于讲次、小节号、定义竖条、例题标签；正文墨色 `#212529`；辅助灰 `#6C757D`；浅底 `#FAF4F5`；分隔线 `#DADCE0`。
- 层级：讲义标题 22pt 黑体；小节 15pt 黑体（编号主色）；块标签 10.5pt 黑体；正文 10.5pt，行距 1.5。
- 页眉：左讲义标题、右“学科学段 · 讲义”，下方细线；页脚居中页码。
