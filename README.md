# MathBank 账号与空间版

这版直接使用本机 MathBank 的完整产品源码，新增账号、团队、权限和空间接入层。原有 `teacher-prep/` 是旧实现，不是这版的运行目录。

## 本机使用

- 地址：`http://localhost:3011`。本系统独立部署，与旧的 3010 实例（`edusystem-gpt` 目录）无关，不再与其同步。
- 超级管理员：`admin`。首次生成的密码保存在 `data/initial-admin.txt`，不在源码或镜像中预置密码。
- Docker：`docker-compose.yml` 的项目名固定为 `mathbank`，容器名 `mathbank`，端口 `127.0.0.1:3011`。
  - 启动或更新代码：`docker compose up -d --build`。`deploy/Dockerfile` 以 `mathbank:base`（已含 Python、TeX、LibreOffice 与字体）为底，只替换代码，不需要联网，几秒完成。更新前可先 `docker tag mathbank:current mathbank:previous` 留回滚。
  - 新机器没有 `mathbank:base` 时，先用根目录的可移植 Dockerfile 构建一次：`docker build -t mathbank:base .`（需联网安装 TeX 等组件）。
- 数据保存在本目录 `data/`（Git 与镜像都不包含）；不要删除。备份前先 `docker compose stop`，不要在服务运行时从 Windows 打开其中的 SQLite 文件。原 MathBank 与旧 teacher-prep 的题目、账号、密钥没有自动迁入。
- 登录后进入上次使用的空间；没有空间的新账号进入“我的 → 空间”，选择学科、学段与教材创建第一个空间。
- 侧栏“我的”集中管理本人账号、密码和空间。管理员还可编辑、重置、停用团队账号，超级管理员维护教材；管理界面嵌入工作台，进入时不重载页面。桌面侧栏顶部（手机顶栏）的空间卡片显示当前空间、学科学段与教材，点击搜索切换。桌面侧栏可收起为一列图标（右上角按钮），选择记在浏览器 cookie 中，由服务端在输出页面时直接应用，刷新不闪动。
- “Q&A”按当前账号与空间版重写，包含账号权限、空间教材、草稿保存、题目录入、组卷导出和模型配置，支持分类筛选与关键词搜索。

## 保留的 MathBank 功能

原版工作台、题库管理、单题编辑器、图片识别、PDF／Word／TeX／Markdown 导入、智能图文识别与裁图、原文证据核验、来源清理、去题号、去题干出处、拆分合并、补图、草稿、查重、题目关联、AI 解答、TikZ 绘图、组卷、试卷管理（原“试卷记录”），以及 PDF／Word／LaTeX 导出均使用原项目代码。

`engine/main.py`、五个主要前端脚本、HTML、CSS、所有导入领域模块从原项目直接复制。原始 SHA-256 清单见 `upstream-manifest.json`。在三个 Windows 兼容修正之外，现已合入 PhysicsBank 的学科规则，增加按学科和学段配置的提示词、物理条件检查、题型和试卷适配。修改范围及哈希记录在 `platform-adaptations.json`，原始两个项目均未改动。

## 新增的组织层

- 账号由超级管理员或团队管理员创建，无自助注册；管理员可改姓名、重置密码、停用账号（立即使登录失效），超级管理员还可调整角色和团队。本人可修改密码。
- 个人、团队共享、公共空间。团队成员默认查看，由管理员授予编辑权限；没有个人之间单独共享。
- **一个空间 = 一个学科 + 一个学段 + 一套教材 = 一个题库。** 三者在创建时选定，之后不能修改（数据库触发器保护），空间名称可由所有者或团队管理员修改。需要其他学段时另建空间，再用跨空间选题复制题目。超级管理员维护可选教材及目录、题型、年级；停用教材只影响新建空间。
- 空间选择面板按学段、学科分组，支持搜索；录入页和编辑器显示“保存到”的空间、学科学段与教材，解析或保存中阻止切换，导入中心有未入库内容时先确认。
- 题库维持原版平铺检索，不加入题库文件树。试卷有空间内两级目录，保存、筛选和移动归档。
- 组卷工具栏的“跨空间选题”列出可访问、且学科学段相同的其他空间，按来源空间、关键词、题型、难度筛选并分页。“复制到本空间并加入试卷”复制题目与题图快照，记录来源空间、来源题号和操作人；同一道题再次加入时直接使用已有副本，并发请求也只产生一份。教材不同时不沿用原章节分类。
- 试卷目录：“试卷管理”左侧为本空间的两级目录树，可直接新建一级目录与子目录、重命名、删除，点目录筛选（一级目录包含其子目录的试卷），把试卷卡片拖到目录或在卡片下拉框中移动。同级目录不能重名；删除目录时子目录一并删除，其中试卷移到上一级（一级目录的移到未归档），试卷本身不删除。组卷“试卷信息”中选择保存目录。
- 选择题选项排列：编辑器预览栏的“选项排列”可选自动、一行四个、两行两个、每行一个，保存为 exam-zh 原生写法 `\begin{choices}[columns=N]`，网页预览、PDF、Word 一致。自动时 PDF 由 exam-zh 按最宽选项计算，网页按渲染宽度实测，Word 用 `engine/mathbank/choice_layout.py` 按相同规则估算（在 36 道真实题上与 PDF 全部一致）。配图为“选项右侧”时固定每行一个。
- 草稿、导入暂存和组卷题篮按浏览器账号＋空间隔离。服务端任务还验证创建者身份。
- 原版双列 AI 设置保留；超级管理员可勾选配置平台默认，团队管理员可配置本团队。空项使用平台默认；已配置的模型调用失败不会切换到另一配置。
- 讲义精细化模块按用户要求后置；原旧系统保留。这版没有新增知识卡。

## 运行结构

浏览器 → 平台 FastAPI（唯一公开端口）→ 该空间的 MathBank worker（仅回环、内部令牌）。

平台代码按职责拆分：`store.py`（表结构与权限）、`migrations.py`（带备份的一次性升级）、`auth.py`（会话与访问检查）、`admin.py`（账号、团队、教材、模型配置）、`spaces.py`（空间、成员、试卷目录、跨空间引用）、`bank.py`（到 worker 的授权代理）、`workers.py`／`worker.py`（进程池与引擎适配）。前端接入在 `platform_app/web/`：`bridge.js`（请求与本地存储隔离）、`space-picker.js`、`paper-tools.js`、`account.js`，样式统一在 `platform.css` 并复用原版主题变量和控件类。

`platform.db` 保存账号、团队、教材、空间、权限、试卷目录、引用来源和审计记录。每个空间的原生 MathBank 数据库、题图、任务和备份位于 `data/banks/<空间 id>/`。请求不会通过切换同一进程全局数据库来实现隔离。

worker 按需启动；Compose 默认最多同时运行 12 个，可用 `MATHBANK_MAX_WORKERS` 调整。达到上限时停止最久未用、且没有进行中请求和导入任务记录的 worker；全部繁忙时明确提示稍后重试，不会丢弃导入结果。模型配置变更在 worker 没有进行中的请求或导入任务时应用。

原生后台关闭、在线自更新与运行组件安装由平台接管，不授予普通教师。Docker 镜像内包含 Pandoc、XeLaTeX、中文字体和 exam-zh 所需 TeX 包。

Linux 的 PDF 编译使用原项目自带的 exam-zh 模板。原版 Windows 的 Times New Roman／Arial／Courier New 在容器中分别以开放字体 XITS／Liberation Sans／Liberation Mono 代替，因此字形与 Windows 有少量差异；题目正文及导出的 LaTeX 源码保持原样。随附 XITS 字体来自 [XITS 项目](https://github.com/aliftype/xits)，许可见 `resources/fonts/xits/OFL.txt`。

## 导入中心与原卷对照

导入中心左栏先是统一的上传区（拖入或选择 PDF／Word／TeX／Markdown，或“粘贴文本”“MinerU 识别”），下面是解析设置。选好试卷后左栏整栏显示原卷，解析设置移到右栏：PDF 用浏览器自带的查看器显示原页；Word 由服务器用 LibreOffice 把原文件转为 PDF 显示（`platform_app/previews.py`，按文件哈希缓存 3 天；镜像需安装 `libreoffice-writer-nogui` 与 `libreoffice-math-nogui`，后者负责公式；左右括号不配对的公式如半开区间 `[1,+∞)` 在 LibreOffice 7.4 中可能显示为“¿”，以原 Word 为准）；TeX、Markdown 和粘贴的文本显示可直接修改的源码。开始解析后设置收起，右栏列出拆出的题目，与左栏原卷逐题对照后入库。两栏之间的分隔条可拖动（28%–70%，记在浏览器中，双击恢复），顶部步骤条随进度变化。界面由 `platform_app/web/import-view.js` 重新排布原版控件（移动而非复制，原版代码仍按 id 使用），样式在 `platform.css`。

**分类名称核对**（移植自 MathBank 3.0.0 的 `mathbank/import_classification.py`）：拆出的题目进入审查前，模型给的学段、章节、小节名称只是写法与目录不同（“第八章”与“8.”、“必修第二册”与“必修二”这类、多余空格、全角数字）时自动对齐；对不上目录、有多个可能或没给的部分清空，只在那道题的卡片上提示“分类待人工选择”，附模型原分类与目录候选，卡片默认不勾选。选好学段和章节，或点“按整章保留”，卡片会重新勾选。PDF、Word、TeX、Markdown 和 MinerU 都一样，不再因为一道题的分类名称让整卷导入失败，也不会因此退回整卷重新拆题。

装上 LibreOffice 后，原版的“Word 原文页视觉复核”（Word 选项中的“自动核对疑点”，默认开启）在容器里也能渲染原页并调用识图模型核对疑点，会增加少量模型调用；不需要时取消勾选即可。

## MinerU 导入

导入中心上传区的“MinerU 识别”适合扫描件、拍照件和图片选项多的试卷。

1. 选择 PDF 或图片，交给 MinerU 识别（需要管理员在“系统设置 → 模型接口”填写 MinerU API Key，团队配置优先，空项用平台默认）。也可以直接上传在 mineru.net 下载的结果包（.zip），不需要 Key。默认勾选“强制 OCR”，避免 PDF 里错误的隐藏文字层。
2. 平台按 MinerU 的版面坐标重建 Markdown（`platform_app/mineru_markdown.py`）：题号统一为 “N．”，小节标题去掉编号；落在图内或图下方的短文字视为图中标注，不进题干；选择题的选项是图片时，按“同一排或对齐网格、尺寸相近”找出 A–D 选项图，其余图留在题干。
3. 配图按每批 20 张自动上传到当前空间，结果作为 .md 源文载入导入中心，左栏显示原卷（上传的 PDF／图片，或结果包里的 `*_origin.pdf`），可切换到“识别文本”查看 Markdown；点“开始解析”后仍由原有的 AI 拆题、公式核对和审查入库完成，`bridge.js` 会把已上传配图的对应关系带给拆题请求。

MinerU 的识别错误（漏行、乱码）不会被自动修正，仍需在审查时对照原卷。

**快速拆题**（MinerU 对话框中默认勾选，按账号和空间记住）：整卷拆题的耗时主要花在模型把每道题重新输出一遍上，而 MinerU 的 Markdown 本身就是原文。勾选后由 `platform_app/mineru_fastpath.py` 在空间 worker 内处理：

- **本地切题**：按小标题分节、按行首题号切段（每节可从 1 重新编号，或接着上一节编号）。每段单独交给引擎的来源结构裁判（与 Word/PDF 快路径同一套题号、选项、答案归属、公式与图片守恒检查）。
- **模型只做判断和分类**：通过裁判的段保留原文，模型只判断各段是不是题，并给出题型、教材分类与难度。分类按每 10 段一批，几批同时请求；少数没通过的段各自整段拆题，也同时进行。
- **出处与配图**：题干开头的"（2019 新课标 3）"在引擎完成原文核对后移入"来源"字段；MinerU 放在选项后面的题图留在选项之外，不会被并进 D 选项。
- **漏掉的填空横线**：MinerU 偶尔会漏掉题末的空。整卷拆题时 AI 会自己补上一个空；快速拆题保留原文不猜，对"判为填空题却没有填空标记"的题给出核对提示。
- **公式写法**：保留 MinerU 原文，不像整卷拆题那样把"Rt△ABC""∠C = 90°"改写成规范公式。引擎只在原文核对能通过时补上明显的公式定界符，所以会出现"∠$C = 90$°"这类写法，显示正常，需要时可在审查时修改。
- **何时退回整卷拆题**：跳号、重号，一节开头有几道题共用的材料或配图，答案集中在卷末，段内引用别的题，不确定的段太多，或分类结果缺题、题型与难度不合约定（章节名称对不上目录不会退回，见上文“分类名称核对”）。
- **后续流程不变**：原文核对、原答案保护、配图映射照常由引擎完成。拆完会提示走了哪条路、用时多少。

**结果缓存**：同一份文件、同样的选项（模型、页码、强制 OCR）再次导入时，复用上次下载的 MinerU 结果包，不再调用 MinerU。缓存在 `data/mineru-cache/`，保留 30 天，超过 2 GB 时先删最久未用的。

## 讲义

侧栏“讲义”用于编写教材式讲义：一套统一版式（哈佛深红点缀、宋体正文、黑体标签），老师只写内容，字体、颜色、间距和编号由模板决定，网页、PDF、Word 三处一致。

- 结构：讲次、标题、副标题、学习目标，然后是按 1、2、3 编号的小节；小节里放正文、定义、定理、性质、公式、推论、证明、注、方法、易错、例题、练习、插图、本节小结。定义、定理、性质、例题、插图在小节内各自编号（定义 1.1、例 1.1……，互不影响），调整顺序后自动更新。
- 题目：例题和练习从本空间题库或组卷题篮选入，插入时保存快照；题库之后修改或删除不影响讲义，编辑器会提示“题库更新”，由老师决定是否同步。
- 导出：PDF 与 Word，各有学生版（例题留白或显示解答，不含答案）与教师版（例题解答、练习答案集中在末尾“参考答案”）。PDF 在空间 worker 内用 exam-zh + `platform_app/templates/handout/mathbank-handout.sty` 编译；Word 由 `platform_app/handout_word.py` 生成，公式可编辑。
- 讲义有自己的两级目录（与试卷目录分开），整份保存在 `platform.db` 的 `handouts` 表，带修订号防止两人互相覆盖；查看者只能阅读和导出。
- 旧讲义（Word/PDF）导入、团队抬头和 AI 辅助编写留到第二期。设计与版式规范见 `docs/HANDOUTS.md`。

## 绘图

侧栏“绘图”是独立的作图区，与题目导入无关，按空间保存，查看者只能浏览和下载。

- **画布**：自托管的 GeoGebra Classic 5.4.933，文件在 `platform_app/vendor/geogebra/`。这个目录不进 Git，由 `scripts/fetch_geogebra.py` 按固定版本下载并核对 SHA-256，构建镜像时一并打包。断网可用；工具、菜单、输入栏与桌面版一致，可以直接拖动调整。
- **AI 作图**：右侧对话框里用文字描述，或附一张参考图（可直接粘贴截图）。
  - 平台在空间 worker 里调用 AI 设置中的“画图模型”（`PREFER_DRAW_MODEL`，与 TikZ 绘图同一个），模型只返回 GeoGebra 指令，由画布执行。
  - 几何图只给少数自由点，其余点用作图指令求出，所以拖动后垂直、中点、相切等关系仍然成立。
  - 有指令执行失败时，会自动请模型修正一次；每一步都可以撤销。含 JavaScript 或设置脚本的指令会被丢弃。
- **保存**：自动保存，带修订号，被别人改过时停止自动保存，让老师选择另存或载入最新版本。保存内容为 .ggb、对话记录和一张自动裁掉白边的 PNG；存入的 .ggb 会去掉其中的 JavaScript。
- **导出**：PNG；.ggb（桌面版 GeoGebra 可打开）；TikZ（复制后可贴进题目编辑器的“新增绘图”）。
- **题目引用**：编辑题目时，题目配图区和图片解答区下方有“从绘图库插入”。选中的绘图以图片副本插入题目，之后再改绘图，不影响已经插入的题目。
- **许可**：GeoGebra 的免费许可仅限非商业使用，见 `platform_app/vendor/geogebra/5.4.933/README.txt` 和 https://www.geogebra.org/license 。商业用途须另与 GeoGebra 签订许可。

## 从多学段空间升级

旧版一个空间可包含多个学段分区。首次启动新版时自动执行一次 `single-bank-spaces-v1` 迁移：先在线备份 `platform.db` 到 `data/migration_backups/`，再让每个旧分区成为独立空间，并沿用分区 id。因此 `data/banks/<id>/`、工作台链接和浏览器草稿都不变，题库文件不移动。含多个学段的空间拆分后名称加学段后缀，如“教研组（初中）”“教研组（高中）”；成员权限复制到每个新空间，试卷目录按空间各复制一份并保持原归档。拆分明细写在备份旁的同名 `.json` 文件中。

## PhysicsBank 物理适配

- `engine/mathbank/subject_profile.py` 接收当前 worker 的学科、学段、管理员元数据；不同学科独立进程，不通过请求临时切换全局学科。单独运行未配置的原生引擎保留高中数学默认行为。
- 物理 OCR、拆题、原文核验/修复、解答、配图定位和 TikZ 绘图增加单位大小写、矢量方向、有效数字、实验表格、电路连接等要求。保留当前 MathBank 的逐图核验、公式锁、来源绑定和有证据的修复链路。
- 拆题题型和难度取自管理员元数据。物理普通试卷按配置顺序分组，实验/计算/简答题均可保存并导出；试卷预览、PDF 和 Word 的学科名称同步为当前学科。初中数学和物理默认普通试卷，高中数学仍默认 19 题模板。
- 首次升级只对仍完整使用原四种数学默认题型的物理教材做一次迁移：增加实验题和简答题，`detailed_answer` 的显示名由“解答题”改为“计算题”。先备份 platform.db；原题型编码、题目、目录、难度不变。已有自定义题型列表不覆盖。新建物理教材若仍提交原四种默认题型，同样转换为六种物理题型。
- 来源与许可见 `PHYSICSBANK-NOTICE.txt`。没有复制旧 PhysicsBank 的数据库、模型配置、账号或密钥。
